# 🐍 Python Flask App

A simple Python Flask application with environment-specific configurations, logging, testing, and CI/CD integration.

## 🚀 Features  
✅ Flask-based Web Application
✅ Logging with `logging` module
✅ Unit Tests with `pytest`

---

## 🛠️ **Setup & Installation**

### **1️⃣ Clone the Repository**
```bash
git clone https://github.com/SrilekhaS20/flask-corporate-app.git
cd flask-corporate-app.git
```

### **2️⃣ Create & Activate Virtual Environment**
```bash
python -m venv venv
source venv/bin/activate   # macOS/Linux
source venv\Scripts\activate      # Windows
```

### **3️⃣ Install Dependencies**
```bash
pip install -r requirements.txt
```

## 🚀 Running the App
### **1️⃣ Run the Flask Application**
```bash
flask run
```

#### App runs on: http://127.0.0.1:5000/

## ✅ **Testing the Application**
### Run Pytest Tests
```bash
pytest tests/
```

#### Ensure that pytest is installed via pip install pytest.
